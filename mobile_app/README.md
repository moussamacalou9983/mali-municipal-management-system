# Application mobile

Cette application mobile React Native est destinee a la collecte terrain et a certaines operations de service liees au systeme municipal.

## Environnements

Fichiers d'exemple :

- [`example.env.dev`](./example.env.dev)
- [`example.env.prod`](./example.env.prod)

Variables principales :

```bash
APP_CONFIG=development|production
BASE_URL=http://votre-api
BRAND_APP_NAME=Systeme de gestion municipale - Mali
BRAND_SHORT_NAME=SGM Mali
BRAND_ORGANIZATION_NAME=Mairie du Mali
BRAND_PUBLIC_WEBSITE_URL=
BRAND_PUBLIC_GITHUB_URL=
BRAND_PUBLIC_YOUTUBE_URL=
```

## Nom affiche

Le nom visible de l'application a ete personnalise en `SGM Mali` sur Android et iOS, sans renommer les identifiants techniques internes du projet.
