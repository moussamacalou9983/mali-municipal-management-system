# Documentation de deploiement

Ce dossier rassemble les ressources necessaires pour deployer la version malienne du projet.

## Structure

- [`deployment_manual`](./deployment_manual) : guides de deploiement
- [`docker_config`](./docker_config) : configuration Docker
- [`database`](./database) : ressources de base de donnees
- [`geoserver_setup`](./geoserver_setup) : configuration GeoServer et impression
- [`sample_import_data`](./sample_import_data) : donnees et fichiers d'import d'exemple

## Usage recommande

1. Preparer l'environnement serveur ou local.
2. Configurer l'application web avec les variables d'environnement adaptees au Mali.
3. Importer ou adapter les donnees de reference locales.
4. Verifier GeoServer, l'impression cartographique et les exports.
