# Introduction

## Objectif

L'objectif de ce document est de presenter le flux de processus technique d'IMIS ainsi que les conventions de developpement appliquees. Cette documentation vise avant tout a expliquer comment IMIS a ete developpe en termes de code, de conventions suivies et de flux de travail du systeme. Ce document sert de reference pour tout developpeur travaillant sur IMIS concernant le flux de travail et les aspects techniques du code.

## Public cible

Public cibles of ce manuel are le coeur systeme developpeurs of IMIS.
