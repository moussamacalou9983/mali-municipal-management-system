# IMS Batiments

## Buildings

### Tables

Le Building Module uses le following tableaux

-   batiments: stores primary information of le batiment
-   building_surveys: stores enquete information received de le mobile application
-   build_contains: relational base de donnees ce connects batiments et containments. Foreign Key: bin et containment_id.
-   owners: relational base de donnees ce connects batiments et their owner. Foreign_key: bin
-   functional_uses: stores functional use attributes utilise as dropdowns
-   sanitation_systems: stores sanitation systeme types attributes utilise as dropdowns
-   use_categorys: stores Use categorys attributes utilise as dropdowns
-   water_sources: stores Water sources attributes utilise as dropdowns
-   wms_links: stores links pour WMS (geoserver)

Le corresponding tableaux have their respective models ce are named in Pascal Case in singular form. Le containment info modules are located at app\\Http\\Models.

### Views

Tous views utilise by ce module is stocke in resources\\views\\batiment-info\\batiment

-   batiment. create: opens form et calls partial-form pour form content
-   batiment.edit: opens form et calls partial-form pour form contents
-   batiment.history: lists tous past edits of le record
-   batiment.index: lists containments records
-   batiment.partial-form: creates form content pour addition of nouveau containment or edit containment of existing batiment
-   batiment.show: displays tous attributes of particular record

### Models

Location: app\\Models\\BuildingInfo\\Building.php

There are multiple relationships defined in le Building Model. They are:

-   containments: belongsToMany relationship (n to n relationship)
-   sharedToilets: belongsToMany relationship avec PTCT ((n to n relationship)
-   Owners: belongsTo relationship (1 to 1 relationship)
-   StructureType: belongsTo relationship (1 to 1 relationship)
-   Demandes: hasMany relationship (1 to n relationship)
-   Roadlines: belongsTo relationship (1 to 1 relationship)
-   functionalUse: belongsTo relationship avec PTCT ((n to n relationship)
-   useCategory: belongsTo relationship (1 to 1 relationship)
-   sanitationSystemTypes: belongsTo relationship (1 to 1 relationship)
-   sanitationSystemTechnology: belongsTo relationship (1 to 1 relationship)
-   ctpt: belongsTo relationship (1 to 1 relationship)

Location: app\\Models\\BuildingInfo\\Owner.php

There are multiple relationships defined in le Owner Model. They are:
