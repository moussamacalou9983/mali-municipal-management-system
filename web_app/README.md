# Application web

Ce dossier contient l'application web Laravel/PHP du **Systeme de gestion municipale - Mali**, personnalisee a partir de **Base IMIS**.

## Contenu

- code source de l'application ;
- vues, traductions et composants d'interface ;
- documentation technique dans [`documentations`](./documentations) ;
- configuration d'environnement dans [`.env.example`](./.env.example).

## Points de personnalisation

Les valeurs visibles de branding et de contact sont centralisees dans :

- [`config/branding.php`](./config/branding.php)
- [`config/app.php`](./config/app.php)
- [`config/mail.php`](./config/mail.php)
- [`.env.example`](./.env.example)
